02 — FLAGSHIP PROJECT

SafeLink SecureVault

A real-time phishing detection system combining a trained ML classifier with an adaptive decision layer — shipped as a Chrome extension with Gmail integration and a sandboxed detonation environment.

Phishing Detection & Contextual Response Engine

An XGBoost classifier trained on ~549,000 URLs powers the core detection layer, fused with a LinUCB contextual bandit that adapts response strategy based on user behavior. Flagged links are detonated in an isolated Docker sandbox with a 15-minute TTL before any verdict reaches the user — all wrapped in a Chrome extension with native Gmail integration.
